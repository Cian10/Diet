# 模块 05–08 实施计划

日期：2026-11-11

## 顺序

1. 营养计算：份量换算、完整性标记、已确认餐食汇总、目标差额与实际热量缺口。
2. 目标引擎：Mifflin–St Jeor、活动系数、阶段调整、可配置宏量营养规则、每日目标历史。
3. LLM：供应商协议、OpenAI 兼容适配器、结构化结果校验、Keychain 与设置仓库。
4. 文本记录：草稿、失败恢复、模型估算、用户编辑确认、重复保存保护。
5. 拍照记录：本地原图、压缩上传副本、统一视觉理解和相同确认流程。
6. 集成：基础今日视图、文本/拍照入口和 API 设置；完整日记与趋势仍留给模块 09。

## 验证

- 使用 Swift Testing 覆盖确定性计算、异常输入、JSON/HTTP 错误、草稿状态和完整记录流程。
- 网络协议测试使用本地 URLProtocol stub，不调用真实供应商。
- 图片测试在进程内生成 JPEG，不访问用户相册或相机。
- 当前没有完整 Xcode，SwiftData、相机权限和 iPhone UI 仍需后续真机验证。
