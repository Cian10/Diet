# 模块 09–11 实施计划

日期：2026-11-11

## 顺序

1. 四标签导航：今天、日记、趋势、我的。
2. 日记：按日查看、原始输入与来源、编辑和删除；每日汇总只统计已确认记录。
3. 趋势：七日有记录天数、平均值、目标完成度、体重和阶段变化；少量数据不生成强结论。
4. 推荐：本地规则、过敏/忌口硬过滤、推荐后营养由计算器复核、超量不提供补偿性建议。
5. 复盘：数据覆盖检查、体重要求、±5% 以内的待确认调整建议、接受/拒绝状态。
6. 通知：本地授权、用餐/进度/每周/阶段提醒、免打扰和页面跳转。

## 验证

- 测试日期归属、草稿排除、七日平均口径、体重趋势和阶段标记。
- 测试推荐过滤、营养改善数值和无网络确定性。
- 测试单日复盘不改变目标、数据不足不建议、接受建议才创建新阶段版本。
- 使用内存通知调度器，不申请真实系统权限；真机通知和跳转后续单独验收。
