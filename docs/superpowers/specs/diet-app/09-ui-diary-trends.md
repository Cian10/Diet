# 09：首页、日记与趋势界面

## 主导航

### 今天

- 当前阶段和当天目标。
- 已摄入、目标差额及宏量营养素完成度。
- 按餐别排列的时间线。
- 文本、拍照和手动记录入口。
- 待确认草稿、错误状态和今日建议。

### 日记

- 日期切换和每日明细。
- 查看食物来源、原始输入、图片及用户修正。
- 编辑或删除记录后重建汇总。
- 同时显示当天实际目标和当前新方案时，以当天目标为准。

### 趋势

- 周平均热量和宏量营养素。
- 目标完成天数、记录完整度和体重趋势。
- 阶段变化标记。
- 数据不足时减少结论，不用少量记录生成确定性评价。

### 我的

- 身体档案、阶段方案和饮食偏好。
- API 配置与连接测试。
- 提醒设置、隐私说明和数据管理。

## 通用状态

每个异步页面需要覆盖空状态、加载、失败、重试和部分成功。模型分析中不得阻止用户查看历史记录。营养数字附单位，估算值有明确标记。

## 可用性

- 主要记录入口在首页容易触达。
- 支持系统动态字体、足够对比度和本地化日期。
- 超量提示使用中性语言，不采用羞辱或焦虑驱动文案。
- 图表不能成为唯一信息载体，应提供对应文本数值。

## 模块验收

- 首页、日记和趋势读取同一来源，不出现相互矛盾的汇总。
- 跨日期、跨零点和修改用餐时间后归属正确。
- 无记录、无网络、API 失败和部分营养未知时界面仍可理解。
- 估算值、用户标签值和手动值可区分。
