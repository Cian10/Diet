# 04：用户档案与健身阶段

## 首次设置

录入完成目标计算所必需的信息，并允许跳过非必需项目：

- 年龄、身高、体重。
- 可选性别、体脂率。
- 日常活动水平和每周训练频率。
- 饮食偏好、忌口、过敏食物。
- 当前阶段、开始日期及目标变化速度。
- 是否区分训练日和休息日。

界面需说明数据用途，并允许稍后修改。缺少必要信息时不生成看似精确的消耗值，应提示补充或由用户直接设置目标。

## 阶段类型

- 增肌：在维持消耗基础上设置适度盈余，具体值由可配置规则和用户确认决定。
- 减脂：设置适度缺口，并提供安全边界提醒，不自动采用极端目标。
- 维持：以维持体重和训练状态为目标。
- 休息／恢复：作为持续阶段单独保存，不与普通训练计划中的休息日混淆。

## 方案规则

1. 每个阶段生成有版本的 `PhasePlan`。
2. 用户可手动覆盖自动建议的热量或营养目标。
3. 修改方案默认从选定日期起生效。
4. 单日训练／休息覆盖只创建对应的 `DailyTarget`，不修改整个阶段。
5. 体重或活动水平变化后可建议重新评估，但不能静默修改目标。

## 页面

- 首次引导。
- 身体档案编辑。
- 当前阶段详情。
- 新阶段创建与历史方案查看。
- 饮食偏好和过敏设置。

## 模块验收

- 创建、结束和切换阶段后，未来目标使用正确版本。
- 历史日记仍显示当天原目标。
- 缺少身体数据时可以采用手动目标完成设置。
- 休息日与休息／恢复阶段在数据和界面上均能区分。
